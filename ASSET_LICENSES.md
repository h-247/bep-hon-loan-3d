# Asset Licenses & Intellectual Property Statement

All assets, characters, 3D procedural models, game simulation logic, user interface components, sound synthesis routines, levels, and recipes in **Bếp Hỗn Loạn** are 100% original creations built for this project.

## Declarations

- **3D Geometry & Materials:** All characters, kitchen stations, appliances, ingredients, and dishes are procedurally generated using Three.js / React Three Fiber primitives (spheres, capsules, cylinders, bevels). No proprietary Overcooked models or textures were copied.
- **Audio:** All sound effects (knives, sizzles, bubbles, bells, buzzers) and background music chords are procedurally synthesized using the standard browser Web Audio API oscillator and gain nodes.
- **Visuals & Branding:** Original branding ("Bếp Hỗn Loạn"), Vietnamese localization, color palettes, and interface layouts.
